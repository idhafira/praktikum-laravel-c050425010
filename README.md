# Praktikum Laravel

Repositori ini berisi kumpulan tugas dan modul praktikum menggunakan framework **Laravel**.

## Deskripsi Singkat
Aplikasi web berbasis Laravel yang mengimplementasikan fitur-fitur esensial seperti manajemen basis data, migrasi, dan seeder untuk keperluan praktikum.

## Langkah Menjalankan Proyek

1. **Instal dependensi PHP:**
   ```bash
   composer install
   ```

2. **Jalankan migrasi database dan seeder:**
   ```bash
   php artisan migrate:fresh --seed
   ```

3. **Jalankan server pengembangan lokal:**
   ```bash
   php artisan serve
   ```
